Git kalkulator
Neki kalkulator u c++
Operacije : plus, minus, pomnozi, podeli, modul, kvadrat
Plus sabira dva broja
Minus oduzima
Multiply mnozi
Opis projekta -> git kalkulator je preprost kalkulator, napisen v programskem jeziku C++, in omogoca izvajanje osnovnih matematicnih operacij nad stevili
Zahteve -> za preverjanje programa potrebujemo prevajalnik C++ g++ in se terminal za izvajanje ukazov
Kompajliranje -> V terminalu v mapi projekta izvedemo ukaz g++ calculator.cpp -o calculator
    S tem prevedemo izvorno datoteko calculator.cpp in ustvarimo izvrsno datoteko calculator
Zagon programa -> V sistemu Windows program zazenemo z ukazom : ./calculator
Seznam operacij -> Sestevanje(pluss), Odstevanje(minuss), Multiply(multiplyy), Divide(dividee), Modulo(moduloo), Kvadriranje(powerr) in se Kvadratni koren(sqrtt)
Avtor -> Dina Jacovic
